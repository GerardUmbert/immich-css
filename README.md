# immich-css

Custom CSS override for the Immich web UI. Paste into **Administration > Settings > Theme > Custom CSS**:

```css
@import url('https://gerardumbert.github.io/immich-css/custom.css');
```

GitHub Pages rebuilds about a minute after each push. Browsers may cache the file for up to 10 minutes; hard-refresh (Ctrl+F5) to see changes sooner.

`immich/` is a local clone of the upstream source used for reference only and is not tracked.
