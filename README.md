# immich-css

Custom CSS override for the Immich web UI. Paste into **Administration > Settings > Theme > Custom CSS**:

```css
@import url('https://cdn.jsdelivr.net/gh/GerardUmbert/immich-css@main/custom.css');
```

jsDelivr caches `@main` for a while; to force an update, pin to a commit hash instead of `main`.

`immich/` is a local clone of the upstream source used for reference only and is not tracked.
